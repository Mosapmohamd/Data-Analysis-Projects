# Global Superstore Analysis (Power BI)

A one-page Power BI sales dashboard built on the **Global Superstore 2016** sample dataset.

## Contents
KPI cards, clustered bar and column charts, a filled map, pie and donut charts, and a slicer for exploring sales and profit across the dataset's dimensions.

## Files
| File | Description |
|---|---|
| `Microsoft Visual Mart.pbix` | Power BI report |
| `global_superstore_2016.xlsx` | Source workbook |

## How to Open
Open the `.pbix` in Power BI Desktop. To refresh, point it to the Excel file.

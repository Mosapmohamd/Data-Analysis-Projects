# Cricket World Cup 2022: Best XI Analysis (Power BI)

A multi-page Power BI report that profiles players from the ICC Men's T20 World Cup 2022 by role and assembles a final team.

## Report Pages
Intro page · Power Hitters/Openers · Anchors/Middle Orders · Finishers/Lower Order Anchors · All-Rounders/Lower Order · Specialist Bowlers · **The Final Team** · Batters / Bowlers / All-Rounders Players Info

Each role page combines KPI cards, area charts, a scatter chart, a table and a slicer, with button navigation between pages.

## Files
| File | Description |
|---|---|
| `Cricket WC 2022 Analysis.pbix` | Power BI report (the data is embedded in the file) |

## How to Open
Open the `.pbix` in **Power BI Desktop**. The player-info pages use the third-party *Image Viewer* custom visual (`ImgViewerVisual`). Import it from AppSource if it does not render. The custom-visual installer files and the image pack from the original working folder are not included.

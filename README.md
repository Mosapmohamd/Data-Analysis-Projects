# Data-Analysis-Projects

A collection of data-analysis projects built with **Python** (pandas, Matplotlib/Seaborn, Plotly Dash) and **Power BI**. Each folder is self-contained, with its own README, data (where size allows) and notebooks or report files.

## Projects

| Project | Tools | Summary |
|---|---|---|
| [Marketing Analysis](Marketing%20Analysis/) | Python, Jupyter | Customer demographics, purchasing behaviour and campaign effectiveness |
| [product Sales Analysis](product%20Sales%20Analysis/) | Python, Jupyter | Sales trends, product performance and brand engagement |
| [Cricket World Cup Analysis](Cricket%20World%20Cup%20Analysis/) | Power BI | T20 World Cup 2022 player profiling by role and a final "best XI" |
| [Hotel Revenue Insights](Hotel%20Revenue%20Insights/) | Power BI | Hospitality KPIs (RevPAR, ADR, occupancy, realisation) on a star-schema model |
| [Sales Dashboard](Sales%20Dashboard/) | Power BI | One-page e-commerce sales and profit dashboard |
| [Telangana Tourism Analysis](Telangana%20Tourism%20Analysis/) | Python, Power BI | Domestic and foreign visitors to Telangana districts, 2016–2019 |
| [Global Superstore Analysis](Global%20Superstore%20Analysis/) | Power BI | Global Superstore 2016 sales dashboard |
| [US Accidents Dashboard](US%20Accidents%20Dashboard/) | Python, Plotly Dash, scikit-learn | Accident EDA, interactive dashboard and severity model |
| [Ford GoBike Analysis](Ford%20GoBike%20Analysis/) | Python, Jupyter | Bike-share trip EDA (April 2019) |
| [Laptop Market Analysis](Laptop%20Market%20Analysis/) | Python, Plotly Dash | Laptop specs and price analysis with an interactive dashboard |

## Requirements

- Python projects: Python 3.9+, `pandas`, `numpy`, `matplotlib`, `seaborn`, `jupyter`. Dash projects also need `dash`, `plotly`, `dash-bootstrap-components`. See each project's README.
- Power BI projects: [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Windows).

Some large raw datasets are not committed. Each affected project's README explains where to get them.

# Ford GoBike Trip Data Analysis (Python)

Exploratory data analysis of Ford GoBike (San Francisco Bay Area bike share) trips from April 2019, in a Jupyter notebook.

## Questions Explored
Trip-duration distribution · duration by user type · trip duration vs user age · peak hours · weekdays vs weekends · usage trend · average duration by hour · most popular start and end stations · duration by start station · stations with the highest imbalance.

## Data
The notebook reads `201904-fordgobike-tripdata.csv` (~49 MB). It is **not committed** because of its size. Download the April 2019 trip-data file from the operator's public system-data page (Ford GoBike, now Bay Wheels) and place it next to the notebook.

## Run
```bash
pip install pandas numpy matplotlib seaborn jupyter
jupyter notebook fordgobike-tripdata.ipynb
```
